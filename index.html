00 · INICIO

CSS desde cero: primero entiende, luego diseña

Aprenderás CSS en un orden pensado para principiantes. Cada lección tiene explicación sencilla, código, vista previa, laboratorio de CSS y un mini proyecto independiente.

Inicio
💡 EXPLICACIÓN FÁCILAntes del código, entiende la idea
🙂
En palabras simples

CSS es el lenguaje que decide cómo se ve una página: color, tamaño, espacio, posición, columnas, animaciones y adaptación a distintos tamaños de pantalla.

🏠
Ejemplo cotidiano

Piensa en HTML como la estructura de una casa y en CSS como pintura, muebles, iluminación y distribución visual.

⚙️
¿Qué pasa por detrás?

El navegador lee las reglas CSS, busca qué elementos coinciden con los selectores y calcula el estilo final que debe dibujar.

🧠
Qué debes recordar

No intentes memorizar propiedades. Aprende a reconocer problemas visuales y a elegir la herramienta CSS adecuada.

01 · FUNDAMENTOS

Preparar un archivo styles.css

CSS no necesita instalación. Para practicar solo necesitas un archivo .css conectado a una página de prueba.

Fundamentos
💡 EXPLICACIÓN FÁCILAntes del código, entiende la idea
🙂
En palabras simples

El archivo styles.css contiene tus reglas. La página de práctica ya aporta la estructura; tú te concentras en el diseño.

🏠
Ejemplo cotidiano

Es como tener un cuaderno exclusivo para todas las decisiones visuales del sitio.

⚙️
¿Qué pasa por detrás?

El navegador carga styles.css y aplica sus reglas al documento. Si el archivo no está enlazado o la ruta es incorrecta, no verás cambios.

🧠
Qué debes recordar

Cuando algo “no funciona”, primero confirma que styles.css realmente se está cargando.

02 · FUNDAMENTOS

Sintaxis, comentarios y selectores

Antes de diseñar layouts necesitas saber cómo apuntar exactamente al elemento que quieres modificar.

Fundamentos
💡 EXPLICACIÓN FÁCILAntes del código, entiende la idea
🙂
En palabras simples

Un selector es la forma de decirle al navegador “aplica estas reglas aquí”. Las clases son la opción más reutilizable para principiantes.

🏠
Ejemplo cotidiano

Es como etiquetar cajas: “todas las cajas con etiqueta destacado tendrán borde azul”.

⚙️
¿Qué pasa por detrás?

El motor CSS compara cada selector con los elementos. Si coincide, incorpora sus declaraciones al cálculo de estilos.

🧠
Qué debes recordar

Usa clases para estilos reutilizables y evita selectores demasiado largos.

03 · FUNDAMENTOS

Cascada, especificidad e herencia

CSS puede recibir varias reglas para el mismo elemento. Entender cómo decide cuál gana evita usar !important sin necesidad.

Fundamentos
💡 EXPLICACIÓN FÁCILAntes del código, entiende la idea
🙂
En palabras simples

La cascada combina origen, importancia, especificidad y orden. La herencia permite que ciertas propiedades pasen del padre a los hijos.

🏠
Ejemplo cotidiano

Es como varias instrucciones sobre la misma camiseta: gana la instrucción con mayor prioridad; si empatan, gana la última.

⚙️
¿Qué pasa por detrás?

El navegador calcula un estilo final por propiedad. Color puede venir de una regla e incluso font-family del padre.

🧠
Qué debes recordar

Cuando una regla no se aplica, revisa primero selector, especificidad y orden antes de añadir !important.

📘 DICCIONARIO RÁPIDO DE ESTA LECCIÓN
Cascadaresuelve conflictos
Especificidadpeso del selector
Herenciapropiedades que pasan del padre
01Qué regla ganaUna clase suele tener más especificidad que un selector de elemento.
EN UNA FRASE

Una clase suele tener más especificidad que un selector de elemento.

styles.css
p { color: #64748b; }

.texto { color: #0f766e; }

.contenedor .texto {
  color: #7c3aed;
}

/* mismo peso: gana la última */
.texto { font-weight: 600; }
Qué debes observar: El texto termina violeta porque .contenedor .texto es más específico que .texto.
Idea clave: Especificidad no significa “mejor”. Busca selectores simples.
Error común: Evita cadenas de IDs y !important salvo casos muy concretos.

04 · FUNDAMENTOS

Colores, unidades y tamaños

Elegir buenas unidades hace que el diseño sea más flexible y fácil de adaptar.

Fundamentos
💡 EXPLICACIÓN FÁCILAntes del código, entiende la idea
🙂
En palabras simples

px es útil para detalles concretos; rem para escalas; % para proporciones; vw/vh para viewport; clamp() permite tamaños fluidos.

🏠
Ejemplo cotidiano

Piensa en px como una medida fija y en rem/% como medidas relacionadas con algo más grande.

⚙️
¿Qué pasa por detrás?

Cada unidad se resuelve contra una referencia distinta. Por ejemplo, rem usa el tamaño raíz y % depende de la propiedad y del contenedor.

🧠
Qué debes recordar

No uses una sola unidad para todo. Usa cada una donde tenga sentido.

📘 DICCIONARIO RÁPIDO DE ESTA LECCIÓN
pxmedida fija CSS
remrelativa a la raíz
clamp()mínimo + fluido + máximo
01Escala flexiblePuedes combinar variables y clamp() para una tipografía que responda al ancho.
EN UNA FRASE

Puedes combinar variables y clamp() para una tipografía que responda al ancho.

styles.css
:root {
  --azul: #1572b6;
  --texto: #0f172a;
}

.titulo {
  color: var(--azul);
  font-size: clamp(2rem, 6vw, 4.5rem);
}

.panel {
  width: min(92%, 720px);
  padding: 1.5rem;
}
Qué debes observar: Reduce y amplía la ventana: el título crece dentro de límites seguros.
Idea clave: clamp(min, preferido, max) es muy útil para fuentes y espacios.

05 · FUNDAMENTOS

Box Model: contenido, padding, border y margin

Todo elemento visible se comporta como una caja. Dominar esta idea evita la mayoría de problemas de tamaño y espacio.

Fundamentos
💡 EXPLICACIÓN FÁCILAntes del código, entiende la idea
🙂
En palabras simples

Padding es espacio interno; margin es espacio externo; border rodea la caja; width/height controlan el contenido o la caja según box-sizing.

🏠
Ejemplo cotidiano

Imagina un regalo: contenido = objeto, padding = espuma, border = caja, margin = distancia con otras cajas.

⚙️
¿Qué pasa por detrás?

Con box-sizing:border-box, el padding y borde se incluyen dentro del ancho declarado, lo que simplifica layouts.

🧠
Qué debes recordar

Usa box-sizing:border-box globalmente para cálculos más predecibles.

📘 DICCIONARIO RÁPIDO DE ESTA LECCIÓN
Paddingespacio dentro
Marginespacio fuera
box-sizingcómo se calcula width
01Caja predecibleLa regla global evita que padding aumente el ancho esperado.
EN UNA FRASE

La regla global evita que padding aumente el ancho esperado.

styles.css
*, *::before, *::after {
  box-sizing: border-box;
}

.caja {
  width: 320px;
  max-width: 100%;
  padding: 24px;
  border: 4px solid #60a5fa;
  margin: 20px auto;
  border-radius: 18px;
  background: #eff6ff;
}
Qué debes observar: La caja mantiene su ancho total aunque tenga padding y borde.
Idea clave: Abre DevTools y observa el diagrama Box Model.

06 · FUNDAMENTOS

Tipografía y legibilidad

Una interfaz clara depende tanto de la tipografía como de los colores o el layout.

Fundamentos
💡 EXPLICACIÓN FÁCILAntes del código, entiende la idea
🙂
En palabras simples

font-family, font-size, font-weight, line-height y letter-spacing controlan la lectura y jerarquía.

🏠
Ejemplo cotidiano

Es como un libro: un título, un subtítulo y un párrafo no deberían tener el mismo peso visual.

⚙️
¿Qué pasa por detrás?

El navegador usa métricas de la fuente para calcular líneas, alturas y saltos. line-height generoso mejora la lectura de párrafos.

🧠
Qué debes recordar

No uses tamaños diminutos. Mantén una jerarquía clara y un ancho de línea cómodo.

📘 DICCIONARIO RÁPIDO DE ESTA LECCIÓN
line-heightaltura entre líneas
font-weightgrosor
chunidad basada en caracteres
01Jerarquía de textoCombina tamaño, peso y ancho de línea para mejorar lectura.
EN UNA FRASE

Combina tamaño, peso y ancho de línea para mejorar lectura.

styles.css
.articulo {
  max-width: 68ch;
  margin-inline: auto;
}

.articulo h2 {
  font-size: clamp(2rem, 5vw, 3.5rem);
  line-height: 1.05;

}

.articulo p {
  font-size: 1.05rem;
  line-height: 1.8;

}
Qué debes observar: El título llama la atención, pero el párrafo sigue siendo cómodo de leer.
Idea clave: ch es útil para limitar el ancho de textos largos.

07 · DISEÑO VISUAL

Fondos, bordes, radios y sombras

Estas propiedades aportan profundidad, agrupación y énfasis sin cambiar el layout principal.

Diseño visual
💡 EXPLICACIÓN FÁCILAntes del código, entiende la idea
🙂
En palabras simples

background puede ser color, gradiente o imagen; border define contorno; border-radius suaviza esquinas; box-shadow crea profundidad.

🏠
Ejemplo cotidiano

Piensa en las tarjetas de una app: fondo separa, borde delimita y sombra eleva.

⚙️
¿Qué pasa por detrás?

Gradientes y sombras se renderizan como capas. Demasiadas sombras grandes pueden afectar rendimiento y claridad.

🧠
Qué debes recordar

Busca sombras suaves y bordes discretos; no conviertas cada elemento en una tarjeta flotante.

08 · LAYOUT

Display, overflow y visibilidad

display decide cómo participa una caja en el flujo. overflow controla qué ocurre cuando el contenido no cabe.

Layout
💡 EXPLICACIÓN FÁCILAntes del código, entiende la idea
🙂
En palabras simples

block ocupa línea completa; inline fluye con texto; inline-block mezcla ambos; none retira el elemento del layout.

🏠
Ejemplo cotidiano

Es como decidir si cada mueble ocupa toda una pared, comparte fila o desaparece temporalmente.

⚙️
¿Qué pasa por detrás?

display modifica el tipo de caja generada. overflow puede recortar, mostrar barras o permitir scroll.

🧠
Qué debes recordar

No uses overflow:hidden para “arreglar” un layout roto sin entender qué se está desbordando.

📘 DICCIONARIO RÁPIDO DE ESTA LECCIÓN
blockcaja de bloque
inlinefluye en línea
overflowcontenido que excede
01Chips y recorteinline-flex es útil para elementos pequeños; overflow controla textos muy largos.
EN UNA FRASE

inline-flex es útil para elementos pequeños; overflow controla textos muy largos.

styles.css
.chip {
  display: inline-flex;
  align-items: center;
  padding: 6px 10px;
  border-radius: 999px;
  background: #e0f2fe;
  color: #075985;
}

.nombre {
  max-width: 220px;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
Qué debes observar: El chip ocupa solo lo necesario y el texto largo se corta con puntos suspensivos.
Idea clave: text-overflow:ellipsis necesita overflow oculto y white-space:nowrap.
